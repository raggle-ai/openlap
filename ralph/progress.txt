## 2026-02-13 - Support project-level config file for CLI defaults
- What was implemented: Added startup config loading from `.openlap.json` or `package.json#openlap` to provide defaults for `model`, `thinking-models`, `thinking-color`, and `no-interactive`, while preserving CLI flag precedence and clear validation errors.

## 2026-02-13 - Add edge case tests for event parsing and large output streaming
